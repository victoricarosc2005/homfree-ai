# HOMFREE AI

Protótipo frontend de uma plataforma de geração de vídeos por IA.

## Como abrir
Abra `index.html` no navegador.

## Próximo passo
O botão GERAR VÍDEO atualmente simula a geração. Para gerar vídeos reais, conecte um backend a uma API/modelo de vídeo e faça o frontend chamar esse backend.

Estrutura:
- index.html — interface
- style.css — visual responsivo
- app.js — upload, preview e fluxo de geração
